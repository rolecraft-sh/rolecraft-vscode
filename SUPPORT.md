## Before Opening an Issue

1. Check the [README](README.md) to see if your question is already answered
2. Search [existing issues](https://github.com/rolecraft-sh/rolecraft-vscode/issues) for similar problems
3. Run `RoleCraft: Doctor` command to diagnose common problems
4. Include your VS Code version and extension version

## Commands

Run these from the Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`):

| Command | Description |
|---------|-------------|
| `RoleCraft: Install Skill` | Install a skill from the registry |
| `RoleCraft: Search Skills` | Search for skills |
| `RoleCraft: List Skills` | List installed skills |
| `RoleCraft: Remove Skill` | Remove an installed skill |
| `RoleCraft: Doctor` | Run diagnostics |
| `RoleCraft: Test Skill` | Test a skill |
| `RoleCraft: Init New Skill` | Create a new skill scaffold |
